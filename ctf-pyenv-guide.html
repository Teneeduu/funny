wsl · ubuntu · ctf

CTF Python 环境搭建

在刚装好的 WSL Ubuntu 里,给打 CTF 用的 Python 搭一套干净环境:每题一个 venv、装好 pwntools 和常用工具链,密码学重型计算再按需接 conda,不再出现装东西权限乱掉的情况。

00

先把系统依赖装齐

pwntools 和一堆 exploit 依赖要编译 C 扩展，缺这些包会直接装失败

一次性系统安装

Ubuntu 终端
bash
sudo apt update
sudo apt install -y build-essential python3-dev python3-venv python3-pip \
  git libssl-dev libffi-dev gdb

这是唯一需要 sudo 的一步，而且只做一次。之后所有 pip 安装都在各自的 venv 里进行，不再需要 sudo。

01

每道题一个独立虚拟环境

不同比赛、不同题目经常要求不同版本的 pwntools 或某个魔改依赖，隔离开最省心

新建题目目录并建 venv

Ubuntu 终端
bash
mkdir -p ~/ctf/比赛名/题目名
cd ~/ctf/比赛名/题目名
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
✓

提示符前面出现 (.venv) 才说明激活成功。之后这道题所有的 pip install 都在这个状态下执行，不加 sudo。

02

装 pwntools 和常用工具链

exploit 编写、gdb 调试、gadget 搜索这几件事的标配组合

1. pwntools 本体

Ubuntu 终端 · 已激活 .venv
bash
pip install pwntools
python3 -c "from pwn import *; print('pwntools ok')"

pwntools 自带了 checksec 命令（pwn checksec ./chall），不用单独再装一个 checksec 工具。

2. pwndbg —— gdb 的可视化调试插件

pwndbg 是全局挂到 ~/.gdbinit 的，不属于某个 venv，装一次全局生效即可，安装脚本本身不需要 sudo：

Ubuntu 终端
bash
cd ~
git clone https://github.com/pwndbg/pwndbg
cd pwndbg
./setup.sh

装完之后随便 gdb ./随便一个二进制，看到 pwndbg 的彩色横幅就说明成功了。

3.（可选）one_gadget

找 one-shot RCE gadget 常用，是个 Ruby 工具，跟 Python 环境无关：

Ubuntu 终端 · 可选
bash
sudo apt install -y ruby ruby-dev
sudo gem install one_gadget
!

WSL 下如果 gdb / pwndbg attach 不上正在跑的进程，多半是 ptrace 权限限制导致的，执行一次（每次重启 WSL 后需要重设，不是永久的）：

bash
echo 0 | sudo tee /proc/sys/kernel/yama/ptrace_scope
03

密码学题需要重型计算库时，再接 conda

不是必装项——遇到格规约、sagemath 这类依赖再装也不迟

什么时候才需要

常规 pwn / re / web 题完全用不到。只有做 lattice attack 之类需要 fpylll、sagemath 这些底层依赖大量 C 库（GMP、MPFR、FPLLL）的密码学题时，才值得装 —— conda-forge 有编译好的二进制，能省掉自己编译这些库的麻烦。

安装 miniconda（不要 sudo）

Ubuntu 终端
bash
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O ~/miniconda.sh
bash ~/miniconda.sh -b -p ~/miniconda3
~/miniconda3/bin/conda init bash

装完关掉重开一次终端，让 conda init 生效。默认新开终端会自动进 (base)，如果不想要可以执行 conda config --set auto_activate_base false。

给密码学题单独开一个 conda 环境

Ubuntu 终端
bash
conda create -n crypto python=3.11 sympy numpy fpylll -c conda-forge
conda activate crypto

这个环境和前面各题目的 .venv 完全独立，互不干扰；不需要的时候 conda deactivate 退出即可。

04

目录结构 & 习惯

按比赛/题目分层，保持权限干净

推荐目录结构

~/ctf/
  └── 2026-somectf/
      ├── pwn-baby/
      │    ├── .venv/  # 这道题专用
      │    ├── chall     # 题目二进制
      │    └── solve.py
      └── crypto-lattice/
          └── solve.sage

每道题独立文件夹、独立 .venv，磁盘空间很便宜，别舍不得建；用完的旧题目目录整个删掉就是干净卸载，不影响其它题目。

三条硬规矩

1. 看到 (.venv) 或 (crypto) 才 pip install，不带前缀提示的命令行不装 Python 包。

2. 系统级依赖（apt、gem）才用 sudo，Python 包永远不用。

3. 项目文件全部放在 ~/ctf/...（Linux 文件系统），不要放到 /mnt/c/...。
